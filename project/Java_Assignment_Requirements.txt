# [실습 과제 조건서] 자바 프로그래밍 실습_02

## 1. 기본 정보
* 담당 교수: 김칠화 교수
* 실시 일자: 2026년 6월 4일
* 과제 주제: 파일 입출력 메소드와 컬렉션을 사용하여 파일 내용을 읽고 쓰고 관리하는 프로그램 작성

---

## 2. 제출 및 유의 사항
1. 작업 공간 지정: 프로그램의 작업공간은 바탕화면의 'final_02_학번' 폴더로 지정합니다.
2. 증빙 자료 작성: 프로그램 실행 화면과 생성된 외부 파일('score.txt', 'juso.txt')을 캡처하여 '학번.ppt' 파일로 작성합니다.
3. 최종 제출: 'final_02_학번' 폴더의 압축파일과 '학번.ppt' 파일을 모두 이클래스(e-Class) 시스템에 제출합니다.

---

## 3. 프로그램 구현 및 기능 요구사항

### 3-1. 핵심 시스템 구조
* 메인 루프: main 메소드 내에서 while문을 사용하여 사용자가 종료 메뉴(7번)를 선택할 때까지 프로그램이 반복 실행되어야 합니다.
* 제어 구조: 사용자의 메뉴 입력에 따라 switch~case문을 사용하여 별도의 메소드나 클래스를 각각 호출하도록 구조화합니다.
* 사용 클래스: 파일 입출력 처리를 위해 FileReader, FileWriter, BufferedReader, BufferedWriter 등의 클래스를 반드시 사용해야 합니다.
* 데이터 보존: 프로그램이 종료되더라도 파일에 기록이 저장되어, 재실행 시 기존 데이터를 유지하고 읽어올 수 있어야 합니다.

### 3-2. 메뉴별 세부 구현 기능 (1번 ~ 7번)
* 메뉴 1 [자기 소개]: 콘솔 화면에 고정된 간단한 자기 소개글을 출력합니다.
* 메뉴 2 [학생성적 입력]: 학생 5명의 이름과 이산구조 과목 성적(중간, 기말, 과제)을 입력받아 HashMap에 저장하고, 지정된 경로(c:\temp\score.txt)의 파일에 기록합니다.
* 메뉴 3 [학생성적 학점 출력]: 파일이나 메모리에 저장된 학생별 성적을 토대로 총점을 계산하고 학점(A+, A0, D+ 등)을 부여하여 양식에 맞게 출력합니다.
* 메뉴 4 [학생 검색]: 저장된 학생 목록 중 입력받은 이름과 일치하는 학생의 성적과 학점을 검색하여 출력합니다. '그만'을 입력할 때까지 반복 검색합니다.
* 메뉴 5 [계산기 프레임]: Swing 등 GUI 프로그래밍을 이용하여 사칙연산 기능과 입력창, 버튼이 포함된 계산기 윈도우 프레임을 화면에 표시합니다.
* 메뉴 6 [학생 주소록 저장, 출력]: 친구 3명의 정보(이름, 나이, 전화번호, 전공, 주소)를 반복 입력받아 지정된 경로(c:\temp\friend.txt)에 저장하고 테이블 형태로 출력합니다.
* 메뉴 7 [끝내기]: 실행 중인 while 루프를 탈출하고 프로그램을 최종 종료합니다.
